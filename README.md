# Project-chakra-
A from-scratch x86 OS in C and assembly with a graphical desktop, TCP/IP and a FAT12 filesystem.

Chakra OS 1.0.0 is a hobby operating system written from scratch for x86 PCs (BIOS boot). It has its own two-stage bootloader, a protected-mode kernel with paging and a heap, preemptive multitasking, an ATA + FAT12 file system with a disk manager, a mouse-driven graphical desktop, a network stack (DHCP, DNS, TCP, HTTP) with a text web viewer, and a USB/Bluetooth foundation. Tested in QEMU; build with make.
